== Pre-Test Issues Found

=== Issue 1: Missing Bitwise Import

*File:* `lib/phronesis/stdlib/rpki.ex`

*Error:*
[source,text]
----
error: undefined function &&&/2
error: undefined function <<</2
error: undefined function bnot/1
----

*Cause:* The bitwise operators (`&&&`, `<<<`, `bnot`) require importing the `Bitwise` module.

*Fix Applied:*
[source,elixir]
----
defmodule Phronesis.Stdlib.StdRPKI do
  import Bitwise  # Added this line
----

=== Issue 2: Deprecated Range Syntax

*File:* `lib/phronesis/library/common/network.ex`

*Warning:*
[source,text]
----
warning: 1..-2 has a default step of -1, please write 1..-2//1 instead
----

*Cause:* Elixir 1.16+ requires explicit step notation for negative ranges.

*Fix Applied:*
[source,elixir]
----
# Before
String.slice(1..-2)

# After
String.slice(1..-2//1)
----

=== Issue 3: Deprecated `use Bitwise`

*File:* `lib/phronesis/stdlib/rpki.ex`

*Warning:*
[source,text]
----
warning: use Bitwise is deprecated. import Bitwise instead
----

*Fix Applied:* Changed from `use Bitwise` to `import Bitwise`.
